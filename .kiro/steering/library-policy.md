# Library fee policy

- Represent all money as integer cents in code, tests, and API responses.
- Treat data from the running BASIC fixture as evidence of observed behavior.
- Ask the developer to approve a change to fee policy before editing an accepted requirement or making the port intentionally diverge.
- For a migration correction, record a failing input as a regression test and run the complete parity suite after changing the corrected port.
